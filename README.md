# OceaNova Action — MVP (One Health Early-Warning System)

OceaNova Action is an agile DeepTech platform engineered under the **"One Health" lens**. It bridges the gap between environmental monitoring and preventive public health by mapping riverine and marine plastic stagnation and translating ecological metrics into a predictive **Microplastic Health Risk Index**.

## Key Frameworks
* **Data Fusion Concept:** Merging macro environmental observations with localized citizen science inputs.
* **Predictive Health Metric:** Modeling water stagnation and pollution density to issue proactive food-chain contamination warnings for health institutions.

## Tech Stack & Architecture
* **Language:** Python 3.10+
* **Dashboard Interface:** Streamlit Framework
* **Geospatial Mapping:** Folium & GeoJSON
* **Core Pipeline:** Private modular data ingestion algorithms (located in the `src/` directory).
